## 📱 Samsung Galaxy S25 Edge'e Uygulama Olarak Kurma

### Android Chrome ile (En Kolay Yol):
1. Telefonda **Chrome** tarayıcısı ile siteyi açın: https://gurakarcem.github.io/ders-takip/
2. Sağ üstteki **⋮ (üç nokta)** menüsüne dokunun
3. **"Uygulamayı Yükle"** veya **"Ana Ekrana Ekle"** seçeneğine dokunun  
4. Onaylayın → Uygulama Play Store'dan indirilmiş gibi telefonunuza kurulacaktır!

> 💡 App Store veya Play Store hesabı gerekmez. PWA (Progressive Web App) teknolojisi sayesinde tam ekran, çevrimdışı çalışan bir uygulama olarak kurulur.

## ✨ Özellikler

| Özellik | Detay |
|---------|-------|
| 📋 Öğrenci Kaydı | Yeni öğrenci kabulü, sınıf bilgisi, iletişim |
| 💰 Ders Ücreti | Her öğrenci için ayrı ders başı ücret belirleme |
| 📅 Ders Kaydı | Tarih, saat, süre ve ödeme durumu ile ders girişi |
| 💳 Ödemeler Sekmesi | Kişisel gider ve ödeme takibi (kredi kartları, ev kirası, faturalar, kredi taksitleri), tarih ve ödeme bilgisi girişi, tek tıkla ödendi/bekliyor kontrolü ve Excel aktarımı |
| 💰 Öğrenci Tahsilatı | Öğrenci ders ücretleri, bakiye, tahsilat dökümü ve ders bazlı ödeme kontrolü |
| 📊 Aylık Matris | Excel benzeri aylık ders sayısı ve gelir tablosu |
| 🗓️ Google Takvim | Dersleri tek tıkla Google Takvim'e aktarma (.ics) |
| 📱 PWA | Telefona uygulama olarak kurulabilir |
| 💾 Çevrimdışı | İnternetsiz de çalışır (Service Worker) |
| ☁️ Bulut Senkronu | Cihazlar arası anlık eşitleme: telefondan veya bilgisayardan girilen en son veri her yerde otomatik güncellenir |
| 🔄 Yedekleme | JSON yedek alma ve Google Drive senkronu |

## 🛠️ Teknoloji

- Saf HTML/CSS/JavaScript (framework yok)
- PWA (Progressive Web App) - Web App Manifest + Service Worker
- LocalStorage ile kalıcı veri saklama
- Chart.js ile interaktif grafikler
